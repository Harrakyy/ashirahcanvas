# Project Rules & Guidelines

## Ponytail: Lazy Senior Developer Philosophy

When modifying or adding code to this project, always adhere to the Ponytail Decision Ladder:
1. **YAGNI:** Skip unnecessary features/abstractions.
2. **Reuse:** Always search the codebase for existing helpers/components before writing new ones.
3. **Stdlib & Native Platform:** Prefer browser/node native APIs over extra libraries.
4. **Minimal Safe Code:** Write concise, readable code. Never sacrifice security, error handling, or accessibility.
